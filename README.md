🎊 **UtsavKart** is a festive e-commerce web app built with **React** and **Tailwind CSS**, designed to bring together the essence of festivals and events on one colorful, dynamic platform.  
It allows users to browse festival- and event-specific items, manage likes, carts, and orders — all within a beautiful, animated, and responsive interface.


## 🌈 Live Preview

🔗 **Visit Here:** [UtsavKart Website](https://divyasrinallatigala.github.io/UTSAVKART/)


## ✨ Key Features

✅ Multi-festival & event browsing — Diwali, Eid, Christmas, Birthdays, Weddings, and more  
✅ Multi-page React structure with routing  
✅ User login & signup interface  
✅ Like, cart, and order management  
✅ Beautiful animations and colorful UI  
✅ Fully responsive design  
✅ Deployed via GitHub Pages for easy access  



## 🧩 Tech Stack

| Technology | Purpose |
|-------------|----------|
| **React.js** | Frontend framework |
| **Tailwind CSS** | Styling and responsiveness |
| **JavaScript (ES6)** | Core scripting |
| **React Router DOM** | Navigation between pages |
| **React Toastify** | Alerts and notifications |
| **gh-pages** | Deployment automation |

## ⚙️ Installation & Setup

1. **Clone this repository**
   git clone https://github.com/divyasrinallatigala/UTSAVKART.git
2. **Navigate to the project**
   cd UTSAVKART/client
3. **Install dependencies**
   npm install
4. **Start the app**
   npm start
5. **Build for production**
   npm run build
6. **Deploy to GitHub Pages**
   npm run deploy**
